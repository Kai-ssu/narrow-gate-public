About

{{ SITE_NAME }}

{{ SITE_NAME }} is a collection of Bible escape rooms for youth groups. Each one is built on a passage of Scripture: teams of 4–8 work through locked stages with an NIV or NKJV Bible, then talk through what they found in a group debrief.

The web app replaces envelopes and padlocks. Each team plays on a phone, reading clue cards and entering codes. A projector backdrop sets the scene in the room, a short story film opens the game, and discussion slides lead the debrief.

How it's built

  • Django checks every code on the server, so answers never appear in the page.
  • Progress lives in a signed cookie instead of a database, so it runs free on Render.
  • The unlock animations are pure CSS, and every sound effect is synthesized in the browser with the Web Audio API. There are no image or audio files.
